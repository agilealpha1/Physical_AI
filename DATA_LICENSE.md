# Data license

The curated catalog data in this repository (`data/projects.jsonl`, `data/paths.json`, generated summaries,
requirements, verification notes and the compiled open-data archive) is dedicated to the public domain under
**CC0 1.0 Universal**.

https://creativecommons.org/publicdomain/zero/1.0/

Project names, descriptions, README excerpts, papers, code, model weights and datasets belong to their respective
authors and are **not** relicensed by this project. Each project keeps its own license; the catalog only organizes
public metadata and links. See each project's `licenses` field and official repository.
